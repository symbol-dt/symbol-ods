前言
思博开放开发标准（Symbol Open Development Standard）是一个自由开放的标准文档库，每个人都可以将自己想到的有助于规范程序开发的标准、协议文档上传。

要求
文件格式
- 采用 Text，Markdown，TeX，HTML 之任一格式编写（至少提供 $ Text 和 Markdown 格式）。
- 使用 ASCII 或 UTF-8 编码储存文本文件。
- 一份标准族存储在同一路径 `/{标准族编号}/`，内部文件按照 `/{标准族编号}/{语言}/{名称}.{类型}` 或 `/{标准族编号}/{语言}/{编号}.{类型}` 命名，如本文件为 `/ods-0/zh-sp/0.md`，附带的资源文件储存在 `/{标准族编号}/src/` 或  `/{标准族编号}{语言}/src/` 下。
- 推荐使用矢量图而非位图。

內容格式
- 文件开头使用 `{标题} ({英文标题}) -- {编号}` 如 `档案规范 (DOCUMENTATION CONVENTIONS) -- ODS 0` 作为标题。
- 后三行使用分别列出 __作者__，__日期__ 和 __版本__ 信息。
- 除了标题和版本信息，其他内容应正确使用中文标点。另外，推荐使用 `「」` 和 `『』` 作为中文引号替换 `‘’` 和 `“”`。
